## 🎯 About This Bootcamp

This repository is a hands-on Go bootcamp for anyone who wants to learn Go—from the fundamentals to more advanced topics.

It is designed to make learning practical and approachable through clear explanations, useful examples, and exercises that help learners apply each concept by writing code.

Whether you are just getting started or want to strengthen your Go skills, you are welcome to learn, practice, and grow with this bootcamp.

- Learn Go step by step, from the basics to more advanced concepts.
- Explore practical examples that explain how each concept works.
- Practice with focused exercises and apply what you learn.
- Use this repository as a learning resource at your own pace.
- Keep building your skills through regular practice.

Section 1 contains exercises on Go fundamentals, including:

- Variables, basic types, and conditions
- `for` loops, `switch`, and error handling
- Strings, UTF-8, bytes, and runes
